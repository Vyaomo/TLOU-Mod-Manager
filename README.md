# TLOU-Mod Manager
**# 最后生还者 MOD 管理器 / TLOU Mod Manager**

- 它使用游戏 PSARC 的索引覆盖机制加载外部 MOD，不会解包或重建数 GB 的 PSARC。

 - It loads external MODs through the game's PSARC index overlay mechanism without unpacking or rebuilding multi-gigabyte PSARC archives.

- ### 安装和使用

1. 启动 `TLOU Mod Manager.exe`。
2. 点击“选择目录”，选择《The Last of Us Part I》的游戏根文件夹，不要选择某个 EXE 文件。正确目录中应有 `tlou-i.exe` 和 `build\pc\main`。
3. 首次使用时点击“扫描游戏归档”，等待 PSARC 索引扫描完成。扫描只读取索引，不会解包游戏归档。
4. 把 MOD 文件夹、`.tloumod`、ZIP 或 RAR 放入管理器程序旁边的 `Mods` 文件夹。
5. 点击“刷新列表”。鼠标移动到 MOD 名称时，左侧会显示该 MOD 的预览图和资料。
6. 勾选 MOD 即可安装；取消勾选即可卸载。改变多个勾选项后，管理器会按当前组合重新应用 MOD。
7. 点击“启动游戏”，或者继续使用平时的方式启动游戏。
- ### Installation and usage

1. Start `TLOU Mod Manager.exe`.
2. Click Browse and select the *The Last of Us Part I* game root folder. Do not select an individual EXE file. A valid folder contains `tlou-i.exe` and `build\pc\main`.
3. On first use, click Scan game archives and wait for the PSARC index scan to finish. Scanning reads only the indexes and does not unpack the game archives.
4. Put the MOD folder, `.tloumod`, ZIP, or RAR beside the manager in its `Mods` folder.
5. Click Refresh. Move the mouse over a MOD name to show its preview image and information on the left.
6. Check a MOD to install it or uncheck it to remove it. After several selections change, the manager reapplies the currently checked combination.
7. Click Launch game, or start the game in your usual way.
